## 2. PAIN (12 minutes)

Pain is a **failed job with a residue**, not a category noun (“marketing”).

| Try that failed | Residue they still have | What they cobbled | Why I believe this |
|---|---|---|---|
| | | | |
| | | | |
| | | | |

Circle **one** residue you can touch with a document this week.

**Pain sentence:** When I try to `________`, I end up with `________`, so I `________` (ugly workaround).

**Not the pain:** “They don’t know about my product.” “The market is crowded.” “They need to be more productive.”

**Evidence quality** (check one):
- [ ] I have heard this in the last 30 days from a named person
- [ ] It is my own residue this month
- [ ] I am guessing — **if this box is checked, do not publish the pain sentence yet.**

## 3. TIME (12 minutes)

### Clock A — When it flares

Day / hour / trigger: `________` because `________`

### Clock B — Time they will actually spend on your file

Honest budget: `______` minutes. Your first win (stopwatch or “unverified”): `______`

If first win > budget, cut the file, don’t add a video.

### Clock C — Time-to-relief after they finish

What is better **the same calendar day?** `________________________________`

If the relief is “in a quarter, pipeline,” you are selling a religion, not a $5–$49 SKU.

**TIME sentence:** This is for the `[hour/trigger]` version of the pain. It takes `[N]` minutes to fill. By tonight they have `[artifact]`.

## 5. Worked example (fictional, zero revenue)

**WHO:** US solo accountant-founders who already file their own 1099s and hang out in a 200-person Slack about bookkeeping, not “finance bros.”  
**PAIN:** Every Sunday night they paste bank CSVs into a color-coded sheet and still miss a contractor. Residue: a tab named `FINAL_v7`.  
**TIME:** Flares Sunday 8pm. They will give a document 20 minutes. Same-night relief: a one-page “did I miss a 1099?” checklist, not a new general ledger.

**Stack sentence:** For US solo accountant-founders who already live in a bookkeeping Slack, when the Sunday-night CSV paste still risks a missed 1099, I sell a one-page miss-checklist they can finish in twenty minutes so tonight’s sheet has a done/not-done line.

**Skip:** agencies, people who want software, people who don’t file 1099s.

These humans and Slack are **illustrative**. Not a case study. No users claimed.
